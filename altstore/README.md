# AltStore-Feed

`source.json` ist als selbst gehosteter Feed vorbereitet. Vor dem Veröffentlichen `OWNER`, `REPOSITORY`, `iconURL`, `versionDate`, `size` und `sha256` ersetzen. Die IPA liegt nach einem GitHub-Release unter dem in der Datei hinterlegten Download-Link.

In AltStore Classic: `Sources` öffnen, `+` wählen und die URL zur veröffentlichten `source.json` eintragen. Die IPA muss von AltStore oder einem anderen Signierweg mit einem eigenen Apple-Account installiert werden. Das ist eine Einschränkung des iOS-Sideloadings, keine Funktion der App.
