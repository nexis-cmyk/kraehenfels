# Krähenfels Audio V4

Die 18 Dateien wurden als getrennte WAV-Generationen in ElevenLabs erzeugt. Atmosphären und Musikflächen sind Schleifen. Effekte sind einzelne Foley-Momente. Die Dateien werden danach auf 48 kHz Stereo und einen moderaten Pegel normalisiert. Die Dateinamen im App-Bundle bleiben aus Kompatibilitätsgründen `V3_*`.

## Import und Prüfung

```powershell
python tools/import_audio_replacements.py _TMP/elevenlabs_v4/import --sync-web
python tools/build_web_preview.py
python tools/validate_project.py
```

Die Validierung prüft Format, Bundle-Synchronität und doppelte Dateien innerhalb einer Szene. Die Prompts sind die Produktionsnotizen. Eine weitere Variante sollte nur nach Hörtest und eindeutiger Cue-Zuordnung den aktuellen Ersatz überschreiben.
